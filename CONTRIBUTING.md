# Contributing

Open an issue before substantial changes to discuss the intended behavior and hardware.

Run the development checks in the README. Add focused regression tests for behavior changes. Use synthetic fixtures: never commit account sessions, passwords, cloud captures, personal device identifiers or learned codes.

For new hardware, describe the model, region and tested commands. Distinguish physical verification from protocol fixtures. Preserve accessory identities and existing configurations; never replay physical commands automatically.

Contributions use this repository's MIT license. Do not submit copied proprietary SDK code or files you lack permission to distribute.
