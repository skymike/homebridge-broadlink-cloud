# Security

Security fixes target the latest release.

Do not report credentials or exploitable vulnerabilities in public issues. Use GitHub's private vulnerability reporting under **Security → Report a vulnerability**.

Include affected versions, a minimal reproduction and the impact. Redact credentials, tokens, device cookies and personal device data. Never attach a live account capture.

The plugin uses an unofficial cloud protocol. Automatic login stores credentials in Homebridge configuration; protect the host, configuration and backups.
